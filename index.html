مكتب الذكاء الاصطناعي والعمليات (ملف واحد متكامل)

تشغيل سريع عبر text.pollinations.ai بدون مفاتيح معقدة، مع تقسيم الأدوار، صندوق اعتماد، رسالة عملاء جاهزة، وإعداد العمل التلقائي في الخلفية.

اختر موظفاً لإسناد مهمة (أو إرسال للكل)

المحادثة مع: رامي — مدير العمليات

المخرجات الجاهزة بانتظار موافقتك

لا توجد مخرجات بانتظار الاعتماد حالياً.

مولّد رسالة واتساب وعرض سريع للعملاء

كيف يعمل النظام وأنت قافل هاتفك؟

ملف index.html يعمل في المتصفح عندما تفتحه، أما التشغيل التلقائي والهاتف مغلق فيتم عبر جدولة سحابية (مثل GitHub Actions) تستدعي text.pollinations.ai وتخزن النتائج في المستودع لتجدها جاهزة عند فتح هاتفك.

name: Auto AI Office Task
on:
  schedule:
    - cron: "0 6 * * *" # كل يوم الساعة 06:00 UTC
  workflow_dispatch:
jobs:
  run:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: |
          mkdir -p reports
          ENC=$(node -e "console.log(encodeURIComponent('أنت سكرتير المكتب. لخص خطوات متابعة العملاء اليومية في 4 نقاط مختصرة.'))")
          curl -s "https://text.pollinations.ai/${ENC}" > "reports/daily-$(date +%F).md"
          git config user.name "OfficeBot" && git config user.email "bot@example.com"
          git add reports/ && git diff --staged --quiet || (git commit -m "تقرير $(date +%F)" && git push)
