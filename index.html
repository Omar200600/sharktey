مكتب الذكاء الاصطناعي والقيادة التنفيذية (ملف واحد متكامل)

إدارة متكاملة بقيادة المدير التنفيذي (فيصل) ومطور المشاريع الربحية (زياد) لدراسة السوق، ابتكار المشاريع، تجهيز قنوات اليوتيوب والمحتوى، وإدارة الفريق عبر text.pollinations.ai بنسخة أولية خفيفة وسريعة على مختلف الأجهزة.

📌 التوجيه المعتمد للمكتب (المرحلة الأولى — 90 يوماً):
  • التركيز العملي: البدء بنسخة ويب خفيفة وسريعة للغرف والقاعات والمعارض والعيادات ثلاثية الأبعاد بواجهة مشرقة ومريحة للعين، مع تقسيم الملفات والمهام لتفادي ثقل الحركة أو الشاشات السوداء على الأجهزة المتوسطة والضعيفة.
  • الربح والباقات: الجمع بين (باقة الانطلاقة السريعة، باقة المؤسسات والمدارس، ومتجر القوالب والمشاهد) مع عرض تجربة مجانية لمدة 7 أيام ونقطة تعادل واضحة.
  • جاهزية الإطلاق: 3 نماذج عرض حية + تخصيص رسائل واتساب + اختبار الأداء على الجوال + اعتماد المخرجات في صندوق الموافقة.

مولّد رسالة واتساب وعرض سريع للعملاء

كيف يعمل النظام وأنت قافل هاتفك؟

ملف العمل يعمل في المتصفح عندما تفتحه، أما التشغيل التلقائي والهاتف مغلق (دراسة السوق، توليد أفكار الفيديوهات، وتقارير المدير التنفيذي) فيتم عبر GitHub Actions وتُحفظ النتائج جاهزة في المستودع:

name: Auto AI CEO & Venture Office
on:
  schedule:
    - cron: "0 6 * * *" # كل يوم الساعة 06:00 UTC
  workflow_dispatch:
jobs:
  run:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: |
          mkdir -p reports
          ENC=$(node -e "console.log(encodeURIComponent('أنت زياد مطور المشاريع وفيصل المدير التنفيذي. ادرس السوق اليوم واقترح فكرة فيديو يوتيوب مربح مع العنوان والوصف والسكريبت المختصر.'))")
          curl -s "https://text.pollinations.ai/${ENC}" > "reports/venture-$(date +%F).md"
          git config user.name "OfficeCEOBot" && git config user.email "bot@example.com"
          git add reports/ && git diff --staged --quiet || (git commit -m "تقرير المشاريع $(date +%F)" && git push)
